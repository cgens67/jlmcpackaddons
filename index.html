Frequently Asked Questions

What is MC Addons? expand_more
MC Addons is a free utility app for Android. It lets you discover, download, and instantly import modifications (addons, worlds, and textures) directly into Minecraft Bedrock with one tap.
Is it free and ad-free? expand_more
Yes, MC Addons is 100% free. It contains absolutely zero advertisements, paid subscriptions, or intrusive tracking.
Does it work with Minecraft Java Edition? expand_more
No. This app is specifically designed for Minecraft Bedrock Edition (Android). It handles `.mcaddon`, `.mcpack`, and `.mcworld` file extensions which are incompatible with Java Edition.
Are the addons safe to use? expand_more
Yes, the addons are sourced from community repositories and are standard Bedrock format files. The app simply manages the downloading and importing process into your local game.
How do I install or update MC Addons? expand_more
You can download the APK directly using the download buttons on this site or from our GitHub Releases page. Simply install the APK file on your Android device (Android 14+).
